# Bundled font provenance

- Manrope400/500/600/700: extracted losslessly from the self-contained Sage & Clay
  HTML guide supplied by the user, converted from WOFF2 to Android-compatible TTF.
  SIL Open Font License1.1; full license in Manrope-OFL.txt. Copyright metadata
  is retained in each tools_manrope_*.txt notice and in the fonts.
- Material Symbols Rounded: official Google variable font, subset to the32 symbols
  referenced by SharedToolComponents. Variation axes FILL,GRAD,opsz,wght retained.
  Apache License2.0; full license in Material-Symbols-LICENSE.txt.

Sources:
https://github.com/google/fonts/tree/main/ofl/manrope
https://github.com/google/material-design-icons/tree/master/variablefont

No runtime downloads or Google Play Services fonts are used.
